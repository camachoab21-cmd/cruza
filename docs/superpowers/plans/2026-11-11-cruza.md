# CRUZA funcional — Implementation Plan
> Execution: superpowers:executing-plans. Desarrollo local sin control de pantalla.
Goal: aplicación académica persistente con roles y diseño de crucigrama.
Architecture: Node 24 + SQLite; API del mismo origen; interfaz modular sin dependencias de ejecución. Conservamos catálogo, vocabulario y lenguaje visual del prototipo y archivamos íntegramente sus archivos.
Spec: docs/ESPECIFICACION.md
Global constraints: bloqueo al cuarto fallo; recuperación antes de habilitación; créditos enteros; permisos por registro; no secretos en Git; publicar avances; no uso de pantalla.
Review focus: autorización por propietario; sesiones bloqueadas; concurrencia de matrícula; porcentajes incompletos; XSS en datos editables.
